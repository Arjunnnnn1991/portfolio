Run Locally
Clone the repository:
bash
git clone https://github.com/Arjunnnnn1991/portfolio.git
Open the folder and double-click index.html in your browser.

No installation needed.

Deploy on GitHub Pages
Push the files to your repository.
Go to Settings > Pages.
Under Branch, select main and / (root), then click Save.
Your site goes live at https://<your-username>.github.io/portfolio/ in a minute or two.
Customize
Edit text, links and stats in index.html.
Change colors in the :root block at the top of style.css:
css
--bg: #0b0f1a;
--accent: #5eead4;
